# Nakaja Design System Skill

## Objective

Apply a consistent cinematic-industrial UI system for Astro components and pages.

## Design Intent

- Premium but practical
- Fast and clear on mobile
- Strong hierarchy around purchase decisions

## UI Foundations

- Dark base with high-contrast text
- Strong CTA color reserved for key actions
- Structured spacing with 8px rhythm
- Product-first imagery and real content

## Required UX Priorities

1. User can find a bike quickly.
2. User can understand financing quickly.
3. User can contact Nakaja via WhatsApp/Messenger quickly.

## Motion Rules

- GSAP: subtle only
- Swiper: gallery-only
- Three.js: only with `modelPath`
- Lenis: only if performance stays within budget

## Accessibility Rules

- Keep readable contrast.
- Keep touch targets comfortable for mobile.
- Keep forms short and clearly labeled.
- Keep disclaimer text visible and legible.

## Financing Disclaimer Rule

Always include where rates appear:

"Rates and approval are subject to financing partner terms. Confirm current offer with Nakaja Bikes."
