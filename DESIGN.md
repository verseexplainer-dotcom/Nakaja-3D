# Nakaja Bikes Design System — Cinematic Velocity

## Purpose

This file is the visual source of truth for Nakaja Bikes.

Nakaja Bikes must feel:

- premium
- rugged
- dark
- mechanical
- fast
- dealership-ready
- Nairobi-market aware
- conversion-focused

The website should look like a premium motorcycle showroom at midnight, built for riders who care about power, durability, daily income, and financing clarity.

## Brand & Style

The design system evokes raw motorcycle power and industrial precision within the Kenyan urban landscape.

The visual mood combines:

- Dark cinematic showroom lighting
- Industrial metal precision
- Racing red energy
- Metallic silver detail
- Glassmorphic data overlays
- Sharp mechanical UI
- Premium motorcycle photography

Motorcycles must remain the visual focus.

UI should support the bike imagery, not compete with it.

## Color Rules

### Main Backgrounds

Use these for the dominant interface:

- Obsidian: `#0e0e0e`
- Charcoal: `#131313`
- Raised charcoal: `#1c1b1b`
- Surface panels: `#201f1f`
